# 抽查叙述中的同源缺陷与扩围决定

青纹检验组的合成抽查、流向和现场名额资料。所有工厂、批次、观察以及规程均为虚构。

资料为 UTF-8 JSON。各类原始记录按编号分组，字段约定见 [资料格式](data/资料格式.md)。资料浏览命令会原样输出记录，添加 `--list` 可只查看各类数量。

使用 Python 3.11，命令只依赖标准库。请在项目根目录运行。

```sh
# 浏览原始资料
python3 -I inspect_records.py data/records.json --list

# 线索分析与下一轮抽点计划（文本报告）
python3 -I survey_analysis.py data/records.json

# 机器可读结果
python3 -I survey_analysis.py data/records.json --json

# 忽略质检员补录，对照补录前的归属、流向与计划
python3 -I survey_analysis.py data/records.json --no-corrections

# 测试
python3 -I -m unittest discover -s tests -v
```

## survey_analysis 的判定规则

工具把原始笔录、运输拆并箱单、供应批次关系、分厂复核说明和现场名额
串成一条证据链，输出六个部分：描述拆解、样品归属、同源证据与扩围触发、
批次流向、抽点计划、签收处置。

- **描述拆解**：按分句拆出部位、缺陷、阳性/否定极性，并单独识别样号、
  样号歧义、对其他笔录的引用，以及是否为维修/换件后复看。否定词只作用
  于所在分句，同一条里的其他阳性（如“未复现转轴裂，划伤仍可见”）不连坐。
- **“未复现”的效力**：只有观察工况与阳性线索**相同**且未经维修时，阴性
  才能作为对照；维修后的复看不替代出货时观察，工况不同的阴性不得宣布撤控。
- **样品归属**：写明完整样号、或交接联只含一个候选样号的，可确认身份；
  引用上一条且交接联相同的复看，继承同一样品号并计为重复记录；样号抄写
  存疑、一箱多个候选的，保留候选归属并标记身份不明，不计入扩围证据。
- **扩围触发**：至少两件**可确认独立**、同一供应批次、相同工况下同一部位
  同类异常的样品才满足。同一序列号的多次复看只算一件；身份不明记录凑不足
  门槛。共享供应件的设备可以同源，但各自不相关的外观问题分成不同证据族。
- **补录改判**：质检员补录可核实来源后，落实样号、判失效误贴的交接联，
  同源证据与外流范围随之改变；用 `--no-corrections` 可查看改判前的结论。
- **箱号重用**：交接以 handover 标识，箱号重复不合并不同交接或去向。
- **抽点优先级**：先覆盖尚未检查、同批次可能已流出的使用点，再安排能区分
  共同零件问题与本地装配问题的对照（同厂异部件批次 / 异厂同部件批次）。
  名额只投向有判别力的现场，没有合格目标时保留名额。
- **签收**：实物签收即占用现场名额，即使后续补录发现原怀疑归错也不退还；
  待落实意向不占名额、可撤回。报告会指出哪些旧现场决定已执行、哪些可撤回。
